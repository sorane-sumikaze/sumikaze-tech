禁止リスト（§1）

  • 押せない文字に --cobalt を使う
  • 読み列の文字・罫・枠に --marine を使う
  • 明るい --emerald を明地の文字に使う
  • ラベル・ナビ・見出し・英文に等幅書体を使う
  • ラベルを大文字化する／字間を 0.04em より広げる
  • 見出しの一語だけを強調する
  • 順序の無い内容に番号の目印を付ける
  • 角丸を 4px / 999px 以外にする。影を使う
  • 読み列に入場アニメーションを置く
  • 読み列の CSS が系統セレクタを参照する

制約（§2）

  • 読み列の文字は 4.5:1 以上。フォーカス表示は 3:1 以上
  • 行幅 --measure 34rem / 38rem（48rem 以上）。1行 40 字以内
  • 独立したリンクは 44×44px 以上。文中のリンクは例外
  • 背景層は読み列の外側の余白にだけ置く。一辺 min(64vmin, 32rem, (100vw − --measure) × 0.6)
  • 日本語の本文に 13px 未満を使わない
  • 情報を色のみで伝えない。現在のページは下線を併用
  • reduced motion：系統は変えず、背景層を静止させる
